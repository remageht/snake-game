# 🐍 Релиз v0.1.1 — Неоновый редизайн и подписанный Android APK

Крупное обновление игры «Змейка»: полностью переработана графика на Canvas, добавлены эффекты частиц и анимация поедания, пересобраны все дистрибутивы под Windows, а также подготовлен и подписан APK для Android.

---

## 🎨 Визуальные улучшения и новые эффекты
- 🟢 **Неоновый градиент змейки**: плавные объемные сегменты с сочным неоновым изумрудным градиентом.
- 👀 **Направленные глазки и анимированный язык**: голова змейки динамически смотрит по направлению движения и периодически высовывает язык.
- 🍎 **Объемное 3D-яблоко**: сферический радиальный градиент, глянцевый блик, реалистичный зеленый листик с черенком, падающая тень и пульсирующая аура свечения.
- 💥 **Система частиц и ударная волна**: при поедании яблока разлетается салют ярких неоновых искр и по телу змейки проходит импульсная волна.
- 🌌 **Киберпанк/Неоновая тема**: глубокий темный фон `#080b12` с деликатной координатной сеткой и неоновыми рамками.

## 📦 Что скачивать и куда ставить

### 🪟 Для пользователей Windows (10 / 11 x64):
1. **`Snake Game_0.1.0_x64-setup.exe` (1.80 МБ)** — **Рекомендуется**. Удобный инсталлятор NSIS с пошаговым мастером установки, созданием ярлыков в меню «Пуск» и на рабочем столе.
2. **`Snake Game_0.1.0_x64_en-US.msi` (2.81 МБ)** — Классический пакет Windows Installer для системной установки.
3. **`snake-game.exe` (8.34 МБ)** — Портативная (Portable) версия. Не требует установки — скачайте и сразу запускайте.

### 📱 Для пользователей Android (смартфоны и планшеты):
- **`snake-game-signed.apk` (10.6 МБ)** — **Подписанный установочный пакет Android (ARM64 / aarch64)**.
  
  **Инструкция по установке на телефон:**
  1. Скачайте `snake-game-signed.apk` прямо на смартфон (или передайте через USB-кабель / Telegram / облако).
  2. Откройте загруженный файл в шторке уведомлений или любом файловом менеджере.
  3. Если система запросит подтверждение — включите ползунок «Разрешить установку из этого источника».
  4. Нажмите «Установить». Пакет подписан официальным цифровым сертификатом (Android Signature Scheme v2 & v3), поэтому установится без ошибок синтаксического анализа.
  5. Откройте приложение «Snake Game» и управляйте змейкой свайпами по экрану!
